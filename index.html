交易规则

公平透明的交易机制

了解内盘和外盘的交易规则，更好地参与 MEME 发射

1

内盘交易 - Agent ID 专属

只有持有 Binance Web3 Agent ID 的用户才能参与内盘交易。 内盘是代币发射的初期阶段，价格最低，机会最大。 每个 Agent ID 地址持仓不可超过总量的 2%， 确保公平分配，防止巨鲸垄断。

2

外盘交易 - 无限制开放

当代币发射完成（内盘售罄）后，自动开放外盘交易。 外盘交易无 Agent ID 要求， 任何人都可以自由买卖，无持仓限制。 流动性自动锁定，保障交易安全。

3

公平发射 - 无预留无预售

所有代币采用公平发射模式， 无团队预留、无私募预售、无白名单。 所有 Agent ID 持有者在同一起跑线参与， 合约开源审计，确保透明公正。

4

流动性锁定 - 资金安全保障

发射完成后，流动性自动锁定 100%， 合约权限放弃，无法增发、无法冻结、无法修改税率。 你的资金由智能合约保护，而非项目方承诺。
